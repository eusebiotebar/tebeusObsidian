# Prompt para Nano Banana — Banner "Command Center"

## Indicaciones

Genera un banner horizontal 1600×400px para una nota de Obsidian llamada "Command Center" (panel de control técnico). La nota se usa como dashboard central de proyectos embedded, automoción, STM32, CAN bus, UDP, y automatización.

## Estilo

- **Fondo:** Oscuro (#0d0d1a a #1a1a2e), gradiente sutil
- **Tema:** Control room / sala de monitorización técnica
- **Look:** Cyberpunk-industrial limpio, estilo NASA/JPL mission control
- **Colores:** Acentos azul eléctrico (#6c8cff), verde neón (#4ade80), cyan (#22d3ee)

## Elementos visuales

- Texto principal: "COMMAND CENTER" en fuente monoespaciada (tipo terminal)
- Subtítulo pequeño: "SYS.ACTIVE" con un LED verde parpadeante
- Líneas de rejilla finas estilo HUD (opcional)
- NO incluir iconos genéricos de "dashboard" (engranajes, velocímetros)
- NO incluir texto secundario más allá del título y subtítulo
- Debe verse profesional, no gaming

## Formato

- 1600×400px, PNG, listo para arrastrar a Obsidian como banner
- Sin bordes blancos ni esquinas redondeadas
- Suficiente contraste para que el texto blanco sea legible sobre el fondo

## Referencia de tono

Como las pantallas de inicio de SpaceX o las interfaces de mission control del JPL — funcional, limpio, con presencia.
